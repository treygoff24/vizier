# Vizier documentation

Vizier is a dictation app for macOS and Linux: tap a key, talk, tap again, and clean text is pasted at your cursor. The [project README](../README.md) is the overview; these pages go into detail, one topic each.

## Using Vizier

| Page | Read it to |
|---|---|
| [Installing](installing.md) | Install the Mac app from the DMG, go through the setup guide, grant permissions, understand updates |
| [Vizier on Linux](linux.md) | Install the `.deb` or AppImage and set up the Linux daemon and `vizier` command: hotkey, pasting, local mode, troubleshooting |
| [The `vizier` command](cli.md) | Every Linux command, exit code and JSON shape |
| [Using Vizier](using.md) | On the Mac, take a dictation, read the strip, use the menu bar popover, History, Re-run and Settings |
| [Modes and configuration](modes-and-config.md) | Pick a mode, edit `vizier.jsonc`, set up fallbacks, cleanup, local models and keys |
| [Vocabulary and replacements](vocabulary-and-replacements.md) | Teach Vizier your words and fix what it gets wrong |
| [Privacy](privacy.md) | See what leaves your Mac in each mode, what is stored, and what is logged |
| [Troubleshooting](troubleshooting.md) | Fix a hotkey, paste, permission or cloud problem, and read the strip's messages |
