# Security

To report a vulnerability, use GitHub's private vulnerability reporting: the "Report a vulnerability" button on this repository's [Security tab](https://github.com/treygoff24/vizier/security/advisories/new). Please do not open a public issue for it.

Include the Vizier version and build (Settings › About, or `Vizier --version`), your macOS version, what you found, and how to reproduce it. Do not include real dictations, audio or API keys; use synthetic audio and made-up text.

This is a one-maintainer project, so replies are best effort. In scope: the app, its update path (Sparkle feed and signatures), key handling in the Keychain, and anything that sends data off the Mac unexpectedly. Out of scope: problems in Apple's, ElevenLabs' or Google's services themselves, and builds from forks.

Only the latest release is supported with fixes.
